# BIBKA Beauty Salon

BIBKA Beauty Salon is a responsive multi-page beauty salon website created for the Advanced CSS: Flexbox & Grid assignment.

## Project Purpose

The purpose of BIBKA Beauty Salon is to help clients learn about beauty services, meet the salon team and book an appointment online.

## Pages

- Home — main information about BIBKA Beauty Salon
- Services — beauty services and prices
- Our Team — information about beauty specialists
- Booking — appointment form and contact information
